# Les Boss — Passeport Voyageur

Prototype Next.js pour écran tactile horizontal.

## Lancer en local

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000

## Déployer sur Vercel

Importer le dossier/repo dans Vercel. Aucun secret ni base de données n'est nécessaire pour cette V1.

## Fonctionnalités

- Format passeport horizontal
- 4 questions
- Animation de page tournée entre les questions
- Scoring séparé profil / destination
- 6 profils et 10 destinations
- Animation finale de tampon de passeport
- Bouton de redémarrage pour le participant suivant

## Étape suivante possible

Ajouter Supabase uniquement si vous voulez enregistrer les résultats et afficher les statistiques en direct pendant la soirée.
